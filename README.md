Quests

A small to-do list app, originally built as a school assignment and extended with custom styling and features.

Features
Add, complete, and remove tasks
Live "tasks left" counter
Visual "All done" state when the list is cleared

Built with
HTML
CSS (custom styling, no framework)
Vanilla JavaScript (DOM manipulation, event listeners, array methods)

What I learned
This project was my first real practice with JavaScript fundamentals — things like looping through arrays, listening for events, and updating the DOM. I ran into (and worked through) bugs around variable scope, mismatched brackets, and silent CSS errors, which taught me a lot about debugging methodically rather than guessing.
